# To-Do-List

A clean, minimalist to-do list web app built with plain HTML, CSS, and JavaScript. No frameworks, no build step — just open the page and start managing tasks.

## Features

- Add, complete, and delete tasks in a simple, distraction-free UI
- Tasks persist across page reloads via browser `localStorage`
- Responsive layout that works on desktop and mobile
- Zero dependencies — single `index.html` file

## Tech Stack

- HTML5
- CSS3 (custom styling, no frameworks)
- Vanilla JavaScript + `localStorage`

## Quick Start

No installation needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/girishlade111/To-Do-List-.git
   cd To-Do-List-
   ```
2. Open `index.html` in any modern browser (or serve it with `python3 -m http.server`).
